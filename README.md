# Number Guessing Game (Python)

A simple command-line game where the computer picks a random number between 1 and 50, and the player keeps guessing until they get it right.

## How it works
- The computer picks a random number using random.randint()
- After every guess, it says "too high" or "too low"
- The loop ends when the guess is correct

## Concepts used
- random module
- while loop and break
- if / elif / else
- input() and int()

## Run
python number_guessing_game.py
